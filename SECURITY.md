# Security Policy

This repository contains documentation and a local calculator. Do not include API keys, browser cookies, login credentials, personal data, or private documents in issues, pull requests, examples, or benchmark cases.

## Reporting a Vulnerability

For a security problem in the repository, use GitHub's private vulnerability-reporting flow when it is enabled for this repository. If it is not available, contact the repository owner through their GitHub profile and include:

- the affected file and revision;
- reproduction steps;
- the potential impact; and
- a safe proof of concept without secrets or personal data.

Please do not disclose a reproducible vulnerability in a public issue before a maintainer has had a reasonable opportunity to respond.
